# array30-phrase-Lim

這是檔案是我修改的官方詞庫，雖然詞庫的使用者很少，但卻是我的生產工具。

原本我都是把自用詞庫塞在檔案後面，避免詞庫發生**版本混亂**，但官方詞庫畢竟是1990年代的產品，裡面有錯字、有過時詞條（如：【雷射唱片】）、也有早已改制的地名（如：「三民鄉」今【那瑪夏區】、「台北縣」今【新北市】）。

一直視而不見也不是辦法，所以我決定動手去弄官方詞庫，並且把我「修正」的東西向官方提issues。這似乎是一舉兩得的方法。

在完成官方詞庫的校對修補前，不適合放入太多的新詞。所以除非必要，我會先將二者分開，先搞定官方詞庫再說。
